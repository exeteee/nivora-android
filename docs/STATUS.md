## Проверка сборки

Запуск workflow №11 завершился ошибкой до начала job. Причина — некорректное отступление heredoc внутри YAML-блока. Исправление добавлено в следующий commit; новый запуск должен подтвердить, что workflow распознаётся.

- Не было проверки на физическом TECNO SPARK Go 2024.
- До распространения требуется собственный Telegram API ID/hash и постоянный release-keystore.
