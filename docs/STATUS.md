# Nivora — статус проекта

Дата фиксации текущего состояния: 15 ноября 2026 года.

## Цель

Неофициальный Android-клиент на основе открытого исходного кода Telegram для Android. Целевое устройство первого цикла проверки — Tecno Spark Go 2024. Основные требования: сохранить базовые функции Telegram, получить отдельный визуальный стиль в духе iOS и убрать интерфейсные продвижения Telegram Premium.

## Уже внесено в ветку work/nivora-foundation

- Отдельное имя приложения: Nivora / Nivora Dev.
- Отдельный Android application ID: `com.nivora.chat`.
- Начальная светлая палитра: синий системный акцент, светло-серый фон и голубой исходящий пузырь сообщений.
- В экране настроек скрыты пункты Premium и Business.
- Удалено системное напоминание Premium grace из экрана настроек.
- В BuildVars подключены собственные `NIVORA_API_ID` и `NIVORA_API_HASH`, передаваемые при сборке.
- Отключена поддержка passkeys, помеченная исходниками как доступная только официальным application ID.
- Удалены скопированные Firebase JSON-файлы и Google Maps API key исходного проекта.
- Удалён тестовый upstream release-keystore; его путь добавлен в .gitignore.
- Добавлен workflow для тестовой Debug APK-сборки, если настроены нужные секреты.

## Пока не выполнено

- Сборка ещё не запускалась с собственными Telegram API/Firebase данными.
- APK не создан, не установлен и не проверен на Tecno Spark Go 2024.
- Полный поиск всех Premium-подсказок и экранов по приложению ещё не завершён. Текущая правка убирает основные пункты в настройках, но не доказывает, что слово Premium нигде больше не встречается.
- Полностью новый iOS-подобный интерфейс ещё не создан: пока изменена только базовая цветовая палитра.
- Не добавлены расширенные функции сообщений, медиа/файлов, поиска, персонализации, групп/каналов и автоматизации.
- Не выполнен аудит сторонних зависимостей, разрешений Android и сетевых подключений.
- Не настроена финальная release-подпись и процесс выпуска обновлений.

## Следующие этапы

1. Получить собственный API ID/hash Telegram и собственный Firebase-конфиг.
2. Собрать Debug APK через GitHub Actions и устранить ошибки сборки.
3. Проверить вход, получение сообщений, уведомления, вложения, звонки и работу интерфейса на реальном устройстве.
4. Завершить аудит Premium-подсказок, проверить, что серверные ограничения Telegram не обходятся.
5. Переработать экраны и навигацию в едином Nivora/iOS стиле.
6. Добавлять дополнительные функции небольшими независимыми изменениями с тестированием после каждого шага.
7. Подготовить release-keystore и выпуск стабильного APK для закрытого круга.

**Важно:** этот документ отражает фактическое состояние исходников, а не обещание готовности продукта или подтверждение успешной сборки.
