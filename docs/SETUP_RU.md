# Подготовка сборки Nivora

Сейчас проект умеет собираться в приватный тестовый APK без ожидания собственного Telegram API ID и без Firebase-конфига.

## 1. Режим временного тестирования Telegram API

Если секреты Telegram API в GitHub не заданы, GitHub Actions использует опубликованную Telegram тестовую пару API ID/hash, которая находится в официальном исходном коде Telegram. Telegram разрешает её только для разработки и тестирования. Серверные ограничения могут сработать, поэтому вход в Nivora с этой парой не гарантирован.

**Этот тестовый APK нельзя распространять друзьям или публиковать.** До любой раздачи приложения необходимо получить собственные api_id и api_hash через https://my.telegram.org/.

Если Telegram позже выдаст собственные реквизиты, добавьте в GitHub Secrets два секрета:
- NIVORA_API_ID — собственный числовой API ID.
- NIVORA_API_HASH — соответствующий hash.

Оба секрета нужно задавать вместе. Если они оба отсутствуют, workflow остаётся в тестовом режиме.

## 2. Firebase и push-уведомления

Для первой тестовой сборки Firebase не обязателен. Без собственного Firebase-конфига приложение может собраться и запускаться, но push-уведомления Firebase не будут настроены. Сообщения и синхронизация должны работать при открытом приложении; фоновые уведомления пока не проверены.

Чтобы включить Firebase позже:
1. Откройте https://console.firebase.google.com/ и создайте свой проект Nivora.
2. Добавьте Android-приложение с точным package name: com.nivora.chat.
3. Включите Firebase Cloud Messaging и скачайте google-services.json.
4. Добавьте GitHub Actions secret GOOGLE_SERVICES_JSON с полным содержимым файла.

Не используйте Firebase-конфиги из исходников Telegram: они относятся к чужому проекту.

Дополнительно можно добавить NIVORA_MAPS_API_KEY — собственный ключ Google Maps SDK for Android. Без него карты могут не загружаться.

## 3. Запуск сборки

Откройте репозиторий https://github.com/exeteee/nivora-android, затем вкладку Actions → Build Nivora Android APK. Последний push в ветку разработки также запускает сборку автоматически.

После успешного завершения откройте запуск workflow и скачайте artifact nivora-debug-apk. Это тестовый APK, подписанный временным debug-сертификатом. Он подходит для проверки на личном устройстве, но не для нормального выпуска и распространения. Для постоянных обновлений понадобится собственный release-keystore.

## 4. Совместимость с устройством

Сборка включает ABI armeabi-v7a и arm64-v8a, а минимальная версия Android в проекте — 6.0 (API 23). TECNO SPARK Go 2024 поставляется с Android 13 Go и чипом Unisoc T606, поэтому по базовой версии Android он подходит. Реальную производительность и стабильность нужно проверить на самом телефоне.

## 5. Уже сделано

- Название приложения — Nivora (английский и русский).
- Package name — com.nivora.chat, приложение устанавливается отдельно от Telegram.
- Добавлена собственная стартовая иконка Nivora и начальная светлая палитра в стиле iOS.
- В настройках убраны пункты Telegram Premium и Telegram Business и напоминание о Premium. Серверные ограничения Premium не обходятся.
- API ID/hash передаются при сборке и не записываются в исходники.
- Firebase-конфиг необязателен для первоначальной тестовой сборки.
- Подготовлен GitHub Actions workflow для сборки APK.

## 6. Ограничения текущей тестовой версии

- Вход на тестовой паре Telegram API может быть ограничен серверами Telegram.
- Firebase push-уведомления без своего Firebase-конфига не работают.
- Google Maps SDK не настроен без собственного ключа.
- APK ещё не проверен на физическом TECNO SPARK Go 2024.
- Более глубокая переработка интерфейса и дополнительные функции ещё не сделаны.
- Общий аудит всех Premium-экранов ещё не завершён.

Не используйте тестовый APK как публичный релиз.
